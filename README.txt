ЛОИҲА: «БАҲИСОБГИРИИ ҲОЗИРШАВИИ ДОНИШҶӮЁН БО РАМЗИ QR»
Версия: 2.0 | PHP 8.1+ | MySQL 8 / MariaDB | XAMPP

1. ТАЛАБОТ
- Windows 10/11 ё Linux
- XAMPP (Apache, PHP 8.1 ё навтар, MySQL/MariaDB)
- PHP extensions: PDO, pdo_mysql, mbstring, openssl, json
- Браузери муосир; барои скан камера иҷозати Camera лозим аст.

2. НАСБ ДАР XAMPP
1) Архивро кушоед.
2) Папкаи bahisobgirii_hozirshavii_qr-ро ба C:\xampp\htdocs\ нусхабардорӣ кунед.
3) XAMPP Control Panel: Apache ва MySQL-ро фаъол кунед.
4) Дар браузер http://localhost/phpmyadmin кушоед.
5) Import -> database.sql -> Go. Пойгоҳи student_attendance_qr сохта мешавад.
6) config/db.php-ро кушоед ва host, dbname, dbuser, dbpass-ро мутобиқ кунед.
7) Ба http://localhost/bahisobgirii_hozirshavii_qr/setup_admin.php дароед.
8) Ному насаб, номи корбар ва пароли мустаҳкамро ворид карда, администратор созед.
9) Баъди сохтани администратор файли setup_admin.php-ро нест кунед ё дастрасии онро маҳдуд намоед.
10) Ба http://localhost/bahisobgirii_hozirshavii_qr/login.php ворид шавед.

3. НАҚШҲО ВА ИМКОНИЯТҲО
АДМИНИСТРАТОР:
- омори умумии система;
- иловаи гурӯҳҳо;
- иловаи омӯзгорон ва донишҷӯён;
- таҳрири маълумоти корбар ва иваз кардани парол;
- фаъол/ғайрифаъол кардани ҳисобҳо;
- нест кардани корбарони иҷозатдодашуда;
- таҳрири номи гурӯҳҳо;
- дидани ҳисоботҳо ва сабтҳои ҳозиршавӣ;
- сабти дастӣ ё ислоҳи ҳозиршавӣ;
- содироти ҳисобот ба CSV (дар Excel кушода мешавад).

ОМӮЗГОР:
- оғози дарси нав барои гурӯҳ;
- намоиши QR-и динамикӣ;
- мониторинги шумораи ҳозиршудагон;
- анҷом додани дарс;
- ҳисоботи пурраи дарс: ҳозир, ғоиб ва фоизи ҳозиршавӣ;
- ислоҳи дастии ҳозиршавӣ дар ҳолатҳои истисноӣ;
- содироти ҳисобот.

ДОНИШҶӮ:
- воридшавӣ бо ҳисоби шахсӣ;
- скан кардани QR аз телефони худ;
- дидани таърихи ҳозиршавӣ;
- дидани танҳо сабтҳои шахсӣ;
- иваз кардани парол.

4. ҚОИДАҲОИ QR ВА ҲОЗИРШАВӢ
- QR аз токени тасодуфии 256-битӣ сохта мешавад.
- Дар база танҳо SHA-256 hash-и токен нигоҳ дошта мешавад.
- Токен ҳар 30 сония нав мешавад; ҳангоми сохтани токени нав токени қаблӣ бекор мешавад.
- Сервер муҳлати токен ва ҳолати дарсро месанҷад.
- Донишҷӯ бояд ба гурӯҳи дарси интихобшуда тааллуқ дошта бошад.
- Индекси UNIQUE барои як донишҷӯ ва як дарс сабти такрориро пешгирӣ мекунад.
- Ҳамаи дархостҳои тағйирдиҳандаи маълумот CSRF token месанҷанд.

5. ИСТИФОДАИ СИСТЕМА
1) Администратор аввал гурӯҳҳоро илова мекунад.
2) Баъд донишҷӯён ва омӯзгоронро сабт мекунад. Барои ҳар донишҷӯ рамзи ягона ворид кунед.
3) Омӯзгор ворид шуда, «Дарс ва QR-код»-ро мекушояд.
4) Номи дарс ва гурӯҳро интихоб карда, дарсро оғоз мекунад.
5) QR дар экран пайдо мешавад ва ҳар 30 сония нав мешавад.
6) Донишҷӯ бо ҳисоби худ аз телефон ворид шуда, «Скан кардани QR»-ро мекушояд.
7) Браузер иҷозати камераро талаб мекунад. QR-и экранро скан кунед.
8) Омӯзгор метавонад «Ҳисоботи пурра»-ро кушояд: рӯйхати ҳамаи донишҷӯёни гурӯҳ бо ҳолати ҳозир/ғоиб.

6. КАМЕРА ВА ДАСТРАСӢ АЗ ТЕЛЕФОН
- Дар ҳамон компютер localhost барои камера иҷозат дода мешавад.
- Агар телефон ба сайт тавассути IP-и компютер ворид шавад, аксари браузерҳо HTTPS талаб мекунанд.
- Барои шабакаи воқеӣ SSL/TLS (HTTPS), домен ё reverse proxy-и дуруст танзимшуда лозим аст.
- Китобхонаҳои Bootstrap, Bootstrap Icons, QRCode.js ва html5-qrcode аз CDN меоянд; барои намуди пурра интернет лозим аст.

7. АМНИЯТ ВА МАҲДУДИЯТҲО
- Паролҳо бо password_hash() нигоҳ дошта мешаванд.
- Сессияи PHP бо HttpOnly ва SameSite=Lax танзим мешавад; session ID баъди воридшавӣ нав мешавад.
- Пас аз 10 кӯшиши номуваффақи воридшавӣ дар равзанаи 15-дақиқаӣ воридшавӣ муваққатан маҳдуд мешавад.
- Дархостҳои база бо PDO prepared statements иҷро мешаванд.
- Дастрасӣ аз рӯйи нақш санҷида мешавад; омӯзгор танҳо дарсҳои худашро мебинад.
- Амалҳои муҳими корбар дар audit_logs сабт мешаванд.
- Файлҳои конфигуратсия ва SQL тавассути .htaccess аз дастрасии мустақим муҳофизат шудаанд.
- Ин лоиҳа барои муҳити таълимӣ/демо омода шудааст. Пеш аз истифодаи истеҳсолӣ: HTTPS, backup-и мунтазам, мониторинги сервер, сиёсати нигоҳдории маълумот, санҷиши амниятӣ ва маҳдудкунии дастрасӣ ба шабака бояд танзим шаванд.
- QR-и навшаванда истифодаи рамзи кӯҳнаро маҳдуд мекунад, вале танҳо QR кафолати ҳузури ҷисмонӣ нест. Барои пешгирии фиреб метавонад тасдиқи омӯзгор, геомаҳдудият (бо розигӣ) ё назорати дохили синф илова шавад.

8. НУСХАИ ЭҲТИЁТӢ
- phpMyAdmin -> Export -> Quick -> SQL.
- Нусхаи папкаи лоиҳа ва пойгоҳи додаҳоро дар ҷойи бехатар нигоҳ доред.
- Пеш аз навсозии версияи система backup гиред.

9. САНҶИШИ ТЕХНИКӢ
Файлҳои PHP бо php -l санҷида шудаанд. Санҷиши воқеии пайвастшавӣ ба MySQL, иҷозати камера ва рафтори браузер бояд дар компютери дорои XAMPP иҷро карда шавад.
