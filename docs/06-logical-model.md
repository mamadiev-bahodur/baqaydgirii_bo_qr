
# Модели мантиқии пойгоҳи додаҳо: attendance_qr

## 1. Ҷадвали ибтидоӣ

Дар оғози таҳлил маълумоти донишҷӯён ва дарсҳо дар як ҷадвал нигоҳ дошта мешавад. Ин ҷадвал шакли ғайринормалӣ дорад.

| Ному насаби донишҷӯ | Гурӯҳ | Омӯзгор | Фан | Санаи дарс | Рамзи QR | Вақти ҳозиршавӣ |
|---|---|---|---|---|---|---|
| Раҳимов Фарҳод | 401 | Сафаров А. | Барномасозӣ | 12.11.2026 | QR001 | 08:05 |
| Назарова Мадина | 401 | Сафаров А. | Барномасозӣ | 12.11.2026 | QR002 | 08:07 |
| Каримов Али | 402 | Ҷӯраев Б. | Пойгоҳи додаҳо | 12.11.2026 | QR003 | 09:10 |

Ин ҷадвал барои нигоҳ доштани маълумот номувофиқ аст, зеро маълумоти гурӯҳ, омӯзгор ва фан такрор мешавад. Инчунин, маълумоти якчанд объект дар як ҷадвал нигоҳ дошта мешавад.

## 2. Нормализатсия

### 1ШН — шакли якуми нормалӣ

Қоидаҳои 1ШН:
- Ҳар як майдон бояд танҳо як қимат дошта бошад.
- Гурӯҳҳои такроршавандаи маълумот иҷозат дода намешаванд.
- Ҳар як сатр бояд бо калиди асосӣ муайян карда шавад.

Дар ҷадвали ибтидоӣ маълумоти донишҷӯ, омӯзгор, фан ва дарс дар як ҷой нигоҳ дошта мешаванд. Барои ислоҳ кардани ин ҳолат маълумот ба ҷадвалҳои алоҳида ҷудо карда мешавад.

### 2ШН — шакли дуюми нормалӣ

Қоидаҳои 2ШН:
- Ҷадвал бояд ба 1ШН ҷавобгӯ бошад.
- Ҳар як атрибути ғайрикалидӣ бояд пурра аз калиди асосӣ вобаста бошад.
- Вобастагии қисмӣ набояд вуҷуд дошта бошад.

Дар модели пешниҳодшуда ҳар як ҷадвал калиди асосии алоҳидаи `id` дорад. Маълумоти донишҷӯён, гурӯҳҳо, фанҳо ва дарсҳо дар ҷадвалҳои мустақил нигоҳ дошта мешавад.

### 3ШН — шакли сеюми нормалӣ

Қоидаҳои 3ШН:
- Ҷадвал бояд ба 2ШН ҷавобгӯ бошад.
- Атрибутҳои ғайрикалидӣ набояд аз дигар атрибутҳои ғайрикалидӣ вобаста бошанд.
- Вобастагии транзитивӣ бояд бартараф карда шавад.

Вобастагиҳои транзитивӣ дар ҷадвали ибтидоӣ:

| Вобастагӣ | Ҳалли масъала |
|---|---|
| Донишҷӯ → гурӯҳ → номи гурӯҳ | Маълумоти гурӯҳ ба ҷадвали `groups` гузаронида шуд |
| Дарс → фан → номи фан | Маълумоти фан ба ҷадвали `subjects` гузаронида шуд |
| Дарс → омӯзгор → ному насаби омӯзгор | Маълумоти омӯзгор дар ҷадвали `users` нигоҳ дошта мешавад |

Пас аз ҷудо кардани маълумот ҳар як ҷадвал танҳо маълумоти ба худ вобастаро нигоҳ медорад. Модели ниҳоӣ ба 3ШН мувофиқ мебошад.

## 4. Алоқаҳои байни ҷадвалҳо

| Алоқа | Навъ | Калиди берунӣ |
|---|---|---|
| groups — users | 1:N | users.group_id |
| groups — lessons | 1:N | lessons.group_id |
| subjects — lessons | 1:N | lessons.subject_id |
| users (омӯзгор) — lessons | 1:N | lessons.teacher_id |
| lessons — qr_tokens | 1:N | qr_tokens.lesson_id |
| users (донишҷӯ) — attendance | 1:N | attendance.student_id |
| lessons — attendance | 1:N | attendance.lesson_id |
| qr_tokens — attendance | 1:N | attendance.qr_token_id |
| users (донишҷӯ) — lessons | M:N | Тавассути attendance |

Алоқаи M:N байни донишҷӯён ва дарсҳо тавассути ҷадвали пайвасткунандаи `attendance` амалӣ карда мешавад. Як донишҷӯ метавонад дар якчанд дарс иштирок кунад ва як дарс метавонад якчанд донишҷӯ дошта бошад.

## 5. Маҳдудиятҳои бутунӣ

### UNIQUE

1. `users.username` — номи воридшавӣ бояд ягона бошад.
2. `groups.name` — номи гурӯҳ такрор нашавад.
3. `qr_tokens.token` — ҳар як рамзи QR бояд ягона бошад.
4. `attendance(student_id, lesson_id)` — як донишҷӯ барои як дарс танҳо як маротиба сабти ҳозиршавӣ дошта метавонад.

### CHECK

1. `CHECK (course BETWEEN 1 AND 6)` — курси таҳсил бояд дар ҳудуди муайян бошад.
2. `CHECK (end_time > start_time)` — вақти анҷоми дарс бояд аз вақти оғоз дертар бошад.
3. `CHECK (expires_at > created_at)` — вақти анҷоми эътибори QR бояд аз вақти сохтан дертар бошад.

### Қоидаҳои ON DELETE

| Калиди берунӣ | Қоида | Сабаб |
|---|---|---|
| users.group_id | ON DELETE SET NULL | Ҳангоми нест шудани гурӯҳ ҳисоб нигоҳ дошта мешавад |
| lessons.group_id | ON DELETE RESTRICT | Гурӯҳи дорои дарсро нест кардан мумкин нест |
| lessons.subject_id | ON DELETE RESTRICT | Фани истифодашавандаро нест кардан мумкин нест |
| lessons.teacher_id | ON DELETE RESTRICT | Омӯзгори дорои дарсро нест кардан мумкин нест |
| qr_tokens.lesson_id | ON DELETE CASCADE | Ҳангоми нест шудани дарс рамзҳои он низ нест мешаванд |
| attendance.student_id | ON DELETE RESTRICT | Донишҷӯи дорои сабти ҳозиршавиро нест кардан мумкин нест |
| attendance.lesson_id | ON DELETE CASCADE | Ҳангоми нест шудани дарс сабтҳои ҳозиршавии он низ нест мешаванд |
| attendance.qr_token_id | ON DELETE RESTRICT | Рамзи истифодашуда то мавҷуд будани сабти ҳозиршавӣ нигоҳ дошта мешавад |

## 6. Хулоса

Дар натиҷаи иҷрои кори лабораторӣ модели мантиқии пойгоҳи додаҳо барои низоми баҳисобгирии ҳозиршавии донишҷӯён бо рамзи QR таҳия карда шуд. Маълумот ба шаш ҷадвали асосӣ ҷудо карда шуд. Калидҳои асосӣ ва берунӣ, алоқаҳои байни ҷадвалҳо ва маҳдудиятҳои бутунӣ муайян карда шуданд.

Модел ба шакли сеюми нормалӣ оварда шудааст. Алоқаи M:N байни донишҷӯён ва дарсҳо тавассути ҷадвали `attendance` амалӣ мегардад. Ҷадвали `qr_tokens` имконият медиҳад, ки рамзҳои QR ҳар 30 сония нав карда шаванд ва вақти эътибори онҳо назорат карда шавад.
